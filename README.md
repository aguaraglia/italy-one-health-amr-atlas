# italy-one-health-amr-atlas

Demo della home di Atlante AMR, portale nazionale della federazione delle edizioni One Health AMR di Sardegna e Lombardia. Un progetto di Codex Vitae ETS.

I conteggi regionali non si sommano: ogni edizione conserva fonti, scale e limiti propri.

Sito: https://aguaraglia.github.io/italy-one-health-amr-atlas/

Il dominio atlanteamr.it arriverà in seguito.

Edizioni regionali:

- Sardegna: https://github.com/aguaraglia/sardinia-one-health-amr-atlas
- Lombardia: https://github.com/aguaraglia/lombardy-one-health-amr-atlas
