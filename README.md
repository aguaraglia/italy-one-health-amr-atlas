# italy-one-health-amr-atlas

Atlante AMR, portale nazionale delle edizioni One Health sull’antimicrobico-resistenza di Sardegna, Lombardia ed Emilia-Romagna. Un progetto di CodexVitae ETS.

I conteggi regionali non si sommano: ogni edizione conserva fonti, scale e limiti propri.

Sito: https://atlanteamr.it/
